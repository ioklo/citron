# 선언 모델 스펙

Updated: 2026-03-06
Status: current

Summary
- 컴파일 파이프라인에서 런타임/중간 선언 인터페이스는 `RDecl`로 통일한다.
- 소스 선언과 외부 노출 선언은 각각 `NDecl`, `EDecl`로 유지하되, 컴파일 단계에서는 `RDecl` 인터페이스로 다룬다.

Rules
- `NDecl`은 소스에서 직접 생성되는 선언이다.
- `EDecl`은 외부 노출 선언이며, `REDecl`로 감싸 `RDecl` 인터페이스를 구현한다.
- `RDecl`은 번역 단계와 중간 표현에서 공통으로 사용하는 선언 인터페이스다.
- `SyntaxIR0Translator`를 포함한 후속 단계는 필요한 선언을 `RDecl` 기준으로 생성/등록한다.

Implications
- 선언 모델은 파이프라인 전반에서 공통 인터페이스를 제공한다.
- 외부 선언과 소스 선언을 하나의 런타임 관점 인터페이스로 다룰 수 있다.
