# AI 문서 색인

이 저장소의 AI 관련 문서 모음입니다. 회의/실험 기록은 `ai/notes`에 남기고, 현재 유효한 표면 언어 규칙과 MIR semantic contract는 `ai/specs`, C++ 구현 결정과 QIR/lowering/evaluator 같은 구현 스냅샷은 `ai/implementations`에 유지합니다.

- `ai/specs/` : 현재 유효한 표면 언어 규칙과 MIR semantic contract
- `ai/implementations/` : MIR/QIR의 C++ 구현 결정, evaluator, lowering 경로, 작업 단위별 구현 스냅샷
- `ai/process/` : 빌드/테스트/CI 관련 절차
- `ai/ai-guidelines/` : AI 에이전트용 작업 규칙과 체크리스트
- `ai/notes/` : 회의록 및 실험 노트
- `ai/templates/` : 스펙/구현 문서 템플릿
